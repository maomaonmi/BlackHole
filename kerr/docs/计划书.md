# Kerr 度规黑洞 - 实现计划书

## 1. 项目背景

### 1.1 原始项目

原始 BlackHole 项目使用**施瓦茨柴尔德度规**（Schwarzschild Metric）渲染非自旋黑洞。该度规假设黑洞质量 M 集中于点，不旋转，因此时空弯曲是**球对称**的。

核心 shader `blackhole.glsl` 使用 Binet 形式的光子加速度公式：
```glsl
a = -(3/2) h² x / r⁵  // 施瓦茨柴尔德测地线
```

### 1.2 升级目标

真实天体物理中的黑洞几乎都在高速自旋。Kerr 度规引入了**角动量参数 a**（0 ≤ a ≤ 1），打破了球对称性，产生**帧拖曳效应**（Frame Dragging）——旋转黑洞拖拽周围时空一起旋转。

### 1.3 实现策略

**将整个 BlackHole 项目备份到 `kerr/` 目录，直接在备份上修改现有代码**，而不是创建独立模块。这样可以：
- 保留完整的渲染管线（桌面捕获、ImGui 界面、粒子系统等）
- 避免重复造轮子
- 快速验证 Kerr 效果

## 2. 数学基础

### 2.1 Boyer-Lindquist 坐标下的 Kerr 度规

```
ds² = -(1 - 2Mr/Σ) dt² - (4Mar sin²θ/Σ) dt dφ
    + (Σ/Δ) dr² + Σ dθ²
    + (r² + a² + 2Ma²r sin²θ/Σ) sin²θ dφ²

其中:
  Σ = r² + a² cos²θ
  Δ = r² - 2Mr + a²
  M = 黑洞质量 (归一化为 1)
  a = 自旋参数 (0 ≤ a ≤ 1)
```

### 2.2 关键结构

| 结构 | 施瓦茨柴尔德 (a=0) | Kerr (a>0) |
|------|-------------------|------------|
| **事件视界** | r = 2M (固定) | r₊ = M + √(M² - a²) |
| **内视界** | 无 | r₋ = M - √(M² - a²) |
| **能层** | 无 | r_ergo = M + √(M² - a² cos²θ) |
| **光子球** | r = 3M | 随 a 和轨道方向变化 |
| **临界冲击参数** | b_crit = 3√3 M | 顺行: ~2M, 逆行: ~5.2M (a接近1时) |

### 2.3 光子测地线方程

在 Kerr 时空中，光子运动有 3 个守恒量：
- **能量 E**（时间平移对称性）
- **角动量 Lz**（绕自转轴的角动量）
- **Carter 常数 Q**（Kerr 时空特有）

光子测地线方程（一阶形式）：

```
Σ² (dr/dλ)² = R(r) = (r² + a² - a Lz/E)² - Δ[(Lz/E - a)² + Q/E²]
Σ² (dθ/dλ)² = Θ(θ) = Q/E² - cos²θ (a² - Lz²/E²/sin²θ)
Σ (dφ/dλ) = (Lz/E)/sin²θ + a(2Mr a E - a² Lz)/Δ - a²
Σ (dt/dλ) = a(Lz/E - a sin²θ) + (r² + a²)(r² + a² - a Lz/E)/Δ
```

### 2.4 从施瓦茨柴尔德到 Kerr 的过渡

施瓦茨柴尔德是 Kerr 在 a=0 时的特例：
- 当 a=0: Σ = r², Δ = r² - 2Mr, Q = 0 (轨道在赤道面)
- 光子加速度退化回: `a = -1.5 h² x / r⁵`

**设计目标**: 通过一个滑条 `uSpinParam` 从 0→1 连续过渡。

## 3. 视觉目标

### 3.1 爱因斯坦环扭曲

| a 值 | 视觉表现 |
|------|---------|
| a=0.0 | 完美圆形爱因斯坦环 |
| a=0.3 | 轻微椭圆拉伸 |
| a=0.6 | 明显不对称，一侧亮一侧暗 |
| a=0.9 | 逗号状扭曲，环结构破碎 |
| a=0.99 | 极端不对称，接近单侧光环 |

### 3.2 吸积盘不对称

- **顺行侧**（与黑洞同向旋转）：更亮，内边缘更靠近事件视界
- **逆行侧**（与黑洞反向旋转）：更暗，内边缘更远
- 多普勒效应因帧拖曳增强，亮度差异可达 3-5 倍

### 3.3 能层可视化

- 事件视界外出现发光薄壳
- 粒子在能层内可提取能量（彭罗斯过程）
- 视觉上表现为半透明发光层包裹黑洞

### 3.4 喷流螺旋化

- 喷流不再严格垂直于吸积盘
- 喷流方向随自转轴进动
- 喷流本身呈锥形螺旋上升

## 4. 技术路线

### 4.1 第一阶段：核心测地线积分器修改

**修改文件**: `blackhole.glsl`

**当前代码**（施瓦茨柴尔德）：
```glsl
// Binet 形式光子加速度（球对称）
vec3 a = -1.5 * h2 * x / (r2 * r2 * r);
// 积分 48 步，简单的 leapfrog 方法
```

**目标修改**：
1. **添加 Kerr 参数**：
   ```glsl
   uniform float uSpinParam;  // 自旋参数 a (0.0~0.99)
   uniform bool  uKerrMode;    // 是否启用 Kerr 模式
   ```

2. **实现 Kerr 测地线积分**：
   - 使用 Boyer-Lindquist 坐标 (r, θ, φ)
   - 哈密顿形式避免符号歧义
   - 4 阶 Runge-Kutta 方法
   - 积分步数增加到 128 步（可调节 48~256）

3. **关键函数**：
   ```glsl
   // Kerr 度规分量
   float sigma(float r, float theta, float a);
   float delta(float r, float M, float a);

   // 逆度规分量
   mat4 inverse_metric(float r, float theta, float a, float M);

   // 哈密顿运动方程
   vec4 dpos_dlambda(vec4 pos, vec4 mom, float a, float M);
   vec4 dmom_dlambda(vec4 pos, vec4 mom, float a, float M);

   // RK4 积分器
   void rk4_step(inout vec4 pos, inout vec4 mom, float dt, float a, float M);
   ```

4. **吸积盘交叉检测**：
   - 修改盘面检测逻辑以适应 Kerr 时空的弯曲轨道
   - 保留赤道面 (θ = π/2) 检测
   - 考虑帧拖曳效应对轨道的影响

### 4.2 第二阶段：能层渲染

**修改文件**: `blackhole.glsl`（添加能层着色逻辑）

**实现内容**：
1. 计算能层边界：
   ```glsl
   float ergosphere_radius(float theta, float a, float M) {
       return M + sqrt(M*M - a*a * cos(theta)*cos(theta));
   }
   ```

2. 渲染半透明发光壳：
   - 在 r₊ < r < r_ergo 区域内添加发光效果
   - 颜色渐变：黑色（视界）→ 淡蓝/紫色（能层外缘）
   - 透明度随距离变化

3. 彭罗斯过程可视化（可选）：
   - 在能层内显示粒子轨迹
   - 模拟能量提取效果

### 4.3 第三阶段：喷流螺旋化

**修改文件**: `blackhole.glsl`（喷流部分）

**实现内容**：
1. 喷流方向偏转：
   ```glsl
   // 根据自旋参数调整喷流方向
   vec3 jet_direction(float a, vec3 spin_axis) {
       float tilt_angle = mix(0.0, 35.0 * PI/180.0, a);
       return rotate(spin_axis, tilt_angle);
   }
   ```

2. 螺旋结构：
   - 喷流粒子沿螺旋路径上升
   - 添加锥形扩散效果
   - 保留现有的喷流渲染逻辑

### 4.4 第四阶段：参数控制和 UI

**修改文件**: `src/gui_config.cpp`, `src/gui_config.h`, `blackhole.glsl`

**实现内容**：
1. 添加 ImGui 控件：
   - `uSpinParam` 滑块（0.0~0.99）
   - `uKerrMode` 开关（Schwarzschild/Kerr 切换）
   - `uIntegrationSteps` 滑块（48~256）
   - `uDiskTemp`, `uDiskGain` 等参数调整

2. 实时预览：
   - 无需重启程序即可看到参数变化
   - 保留所有现有功能（桌面捕获、粒子系统等）

### 4.5 兼容性保证

**关键设计**：
1. **Schwarzschild 极限**：当 `uSpinParam = 0.0` 或 `uKerrMode = false` 时，自动退化为 Schwarzschild 行为
2. **性能权衡**：提供积分步数调节，用户可根据 GPU 性能选择
3. **数值稳定性**：
   - 限制 a ≤ 0.99（避免极端 Kerr）
   - 近视界区域使用自适应步长
   - 添加边界检查防止除零错误

## 6. 风险与挑战

| 风险 | 等级 | 应对策略 |
|------|------|----------|
| **数值积分不稳定** | 高 | 使用自适应步长 + RK4，近视界区域增加精度 |
| **性能下降** | 高 | 128步 vs 48步，预期 2-3x 性能损失；提供步数调节 |
| **Shader 代码复杂度** | 中 | 模块化设计，将 Kerr 函数独立成函数块 |
| **a→1 极端情况** | 高 | 限制 a ≤ 0.99，近极端时使用更小步长 |
| **能层渲染复杂** | 中 | 先实现简化版，后续迭代优化 |
| **与现有功能冲突** | 低 | 完整备份项目，保留所有现有功能 |
| **调试困难** | 中 | 使用 RenderDoc 等工具，添加可视化调试输出 |

### 8.3 性能预期

| 积分步数 | 性能影响 | 适用场景 |
|---------|---------|---------|
| 48 步 | 基准（原版） | 低端 GPU，快速预览 |
| 96 步 | ~2x 性能损失 | 中端 GPU，平衡质量和性能 |
| 128 步 | ~2.7x 性能损失 | 高端 GPU，推荐设置 |
| 256 步 | ~5.3x 性能损失 | 极致质量，截图/录屏 |

**注意**：a 接近 1 时，建议增加积分步数以保持数值稳定性。
