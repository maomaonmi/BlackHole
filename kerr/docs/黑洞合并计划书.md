# 黑洞合并模拟计划书

## 概述

利用现有的小黑洞（恒星演化最终阶段 STAGE_BLACK_HOLE）与主体大黑洞，模拟引力波合并事件的三阶段过程：**旋近 → 并合 → 铃宕**。

## 物理背景

黑洞合并分为三个阶段：

| 阶段 | 物理过程 | 视觉表现 | 持续时间 |
|------|---------|---------|---------|
| 旋近 (Inspiral) | 两黑洞绕转，轨道因引力波辐射逐渐衰减 | 螺旋轨道，频率递增的引力波涟漪 | ~10-15秒 |
| 并合 (Merger) | 视界融合，剧烈能量释放 | 全屏白光闪烁，强引力波爆发 | ~1-2秒 |
| 铃宕 (Ringdown) | 新黑洞振荡稳定 | 准正则振荡衰减，涟漪逐渐消失 | ~5-8秒 |

## 实现方案

### Phase 1: 合并状态机与触发机制

**文件**: `main.cpp`, `gui_config.h`, `gui_config.cpp`

新增合并状态枚举：
```cpp
enum MergerPhase {
    MERGER_IDLE,       // 未触发合并
    MERGER_INSPIRAL,   // 旋近阶段：螺旋衰减
    MERGER_MERGER,     // 并合阶段：碰撞融合
```

```cpp
int   mergerPhase;          // 当前合并阶段

float mergerOrbitAngle;     // 当前轨道角度
float mergerOrbitSpeed;     // 当前角速度
```

在 `BlackholeConfig` 中新增配置：
```cpp

float mergerMergerDur     = 1.5f;   // 并合持续时间(秒)

float mergerFinalRadius   = 0.02f;  // 合并触发半径(UV)

```

**触发方式**：
- ImGui 按钮"触发黑洞合并"
- 快捷键（如 `M` 键）
- 仅当 `stage == STAGE_BLACK_HOLE && evo == EVO_IDLE` 时可触发

### Phase 2: 旋近阶段 (Inspiral)

**文件**: `main.cpp`

物理模型 — 简化的引力波轨道衰减：

```cpp
if (s.mergerPhase == MERGER_INSPIRAL) {
    s.mergerTimer += dt;
    float progress = s.mergerTimer / config.mergerInspiralDur;  // 0..1

    // 轨道半径从初始值指数衰减到合并半径
    // r(t) = r0 * (1 - progress)^0.25  (Post-Newtonian近似)
    float r = config.mergerInitialRadius *
              powf(1.0f - progress, 0.25f);
    r = fmaxf(r, config.mergerFinalRadius);

    // 角速度 ~ r^(-1.5) (Kepler)，频率随轨道收缩递增
    // chirp signal: f(t) ~ (t_coalesce - t)^(-3/8)
    float omega = 0.8f * powf(config.mergerInitialRadius / r, 1.5f);
    s.mergerOrbitAngle += omega * dt;
    s.mergerOrbitSpeed = omega;

    // 小黑洞位置：围绕主黑洞螺旋
    s.x = bhCx + r * cosf(s.mergerOrbitAngle);
    s.y = bhCy + r * sinf(s.mergerOrbitAngle);

    // 传递引力波频率给shader（涟漪频率随轨道频率递增）
    s.mergerRingdownAmp = progress;  // 振幅随接近合并而增大

    // 进入并合阶段
    if (progress >= 1.0f) {
        s.mergerPhase = MERGER_MERGER;
        s.mergerTimer = 0.0f;
        s.mergerFlash = 1.0f;
    }
}
```

**shader 侧** — 增强引力波涟漪：
- 涟漪频率跟随轨道频率（chirp signal）
- 涟漪振幅随旋近进度递增
- 新增 uniform：`uMergerPhase`, `uMergerProgress`, `uMergerGWFreq`

### Phase 3: 并合阶段 (Merger)

**文件**: `main.cpp`, `star_frag.glsl`, `blackhole.glsl`

```cpp
if (s.mergerPhase == MERGER_MERGER) {
    s.mergerTimer += dt;
    float progress = s.mergerTimer / config.mergerMergerDur;  // 0..1

    // 小黑洞迅速被吸入，尺寸缩小
    s.size *= (1.0f - dt * 3.0f);
    s.bhFormationProgress = fmaxf(0.0f, 1.0f - progress * 2.0f);

    // 闪光强度：快速上升后衰减
    if (progress < 0.3f) {
        s.mergerFlash = progress / 0.3f;  // 上升到峰值
    } else {
        s.mergerFlash = 1.0f - (progress - 0.3f) / 0.7f;  // 衰减
    }

    // 进入铃宕阶段
    if (progress >= 1.0f) {
        s.mergerPhase = MERGER_RINGDOWN;
        s.mergerTimer = 0.0f;
        s.mergerFlash = 0.3f;  // 铃宕初始振幅
    }
}
```

**视觉效果**：
- **全屏闪光**：在主 shader (`blackhole.glsl`) 中添加白光叠加
- **冲击波**：从合并中心向外扩散的环形波纹
- **小黑洞淡出**：bhFormationProgress 降为0，视觉上被吸收

### Phase 4: 铃宕阶段 (Ringdown)

**文件**: `main.cpp`, `blackhole.glsl`

```cpp
if (s.mergerPhase == MERGER_RINGDOWN) {
    s.mergerTimer += dt;
    float progress = s.mergerTimer / config.mergerRingdownDur;  // 0..1

    // 准正则振荡 (Quasi-Normal Mode) 衰减
    // A(t) = A0 * exp(-t/tau) * cos(omega_QNM * t)
    float tau = config.mergerRingdownDur * 0.3f;  // 衰减时间常数
    float omegaQNM = 15.0f;  // QNM频率
    s.mergerRingdownAmp = expf(-s.mergerTimer / tau) *
                          cosf(omegaQNM * s.mergerTimer);

    // 引力波涟漪振幅逐渐衰减
    s.mergerFlash = expf(-s.mergerTimer / tau) * 0.3f;

    // 完成
    if (progress >= 1.0f) {
        s.mergerPhase = MERGER_DONE;
        s.state = STAR_DEAD;  // 小黑洞消失
        // 主黑洞略微增大（吸收了质量）
        // 通过 config.holeRadius 临时增大实现
    }
}
```

**视觉效果**：
- **主黑洞振荡**：视界半径轻微振荡（±5%），模拟新黑洞的振铃
- **衰减涟漪**：引力波涟漪振幅指数衰减
- **主黑洞增大**：合并完成后主黑洞半径增大约10-15%

## 风险与注意事项

1. **小黑洞位置覆盖**：旋近阶段小黑洞位置由轨道物理控制，需跳过现有的鼠标跟随逻辑
2. **渲染顺序**：并合闪光需在主 shader 之后叠加，避免被其他效果覆盖
3. **性能**：引力波涟漪在并合阶段频率极高，需限制最大采样次数
4. **状态恢复**：合并完成后需正确重置小黑洞状态，允许再次创建恒星
5. **主黑洞增大**：合并完成后主黑洞半径增大需平滑过渡，避免突变
