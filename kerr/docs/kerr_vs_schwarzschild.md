# Kerr vs 施瓦茨柴尔德 - 视觉对比

## 概述

本文档对比施瓦茨柴尔德度规（非旋转黑洞）和 Kerr 度规（旋转黑洞）在视觉效果上的差异。

## 1. 爱因斯坦环

### 施瓦茨柴尔德 (a = 0)

- **形状**：完美圆形
- **对称性**：完全中心对称
- **亮度分布**：均匀的环状结构

### Kerr (a > 0)

- **a = 0.3**：轻微椭圆拉伸（~5%），仍接近圆形
- **a = 0.5**：明显椭圆（~15%），环的一侧开始变亮
- **a = 0.7**：显著扭曲（~30%），左右不对称明显
- **a = 0.9**：逗号状分布，环结构开始破碎
- **a = 0.99**：几乎退化为单侧弧形光斑

**物理原因**：帧拖曳效应使光子轨道不再对称。顺行光子（与黑洞同向旋转）轨道更稳定，逆行光子轨道更不稳定。

## 2. 事件视界

| 参数 | 施瓦茨柴尔德 | Kerr (a=0.5) | Kerr (a=0.7) | Kerr (a=0.9) | Kerr (a=0.99) |
|------|-------------|-------------|-------------|-------------|---------------|
| 视界半径 | 2.0 M | 1.87 M | 1.71 M | 1.44 M | 1.14 M |
| 形状 | 完美球形 | 略微扁球 | 扁球 | 明显扁球 | 极端扁球 |

**注意**：虽然事件视界本身是球形的，但视觉上看起来更小的原因是引力透镜效应将更多光线吸入。

## 3. 能层

| 施瓦茨柴尔德 | Kerr |
|-------------|------|
| 无能层 | 事件视界外有发光壳层 |
| 无 | 能层厚度随 a 增大 |
| 无 | 彭罗斯过程粒子可见 |

**能层厚度**（赤道面）：
- a = 0：无
- a = 0.3：0.05 M
- a = 0.5：0.13 M
- a = 0.7：0.29 M
- a = 0.9：0.56 M
- a = 0.99：0.86 M

## 4. 吸积盘

### 施瓦茨柴尔德

- 盘面完全对称
- 前盘和后盘亮度由多普勒效应决定
- 内边缘固定在 r = 3M（ISCO）

### Kerr

- **顺行侧**（与黑洞同向旋转）：更亮，内边缘更近
- **逆行侧**（与黑洞反向旋转）：更暗，内边缘更远
- 亮度差异可达 2-5 倍

**ISCO 位置**（最内稳定圆轨道）：

| a 值 | 顺行 ISCO | 逆行 ISCO |
|------|----------|----------|
| 0.0 | 6.0 M | 6.0 M |
| 0.5 | 4.2 M | 7.8 M |
| 0.7 | 3.4 M | 8.5 M |
| 0.9 | 2.3 M | 9.0 M |
| 0.99 | 1.45 M | 9.0 M |

## 5. 喷流

### 施瓦茨柴尔德

- 严格垂直于吸积盘
- 双向对称
- 直线或轻微摆动

### Kerr

- **自转轴进动**：喷流方向随自转参数 a 偏转
- **螺旋结构**：喷流呈锥形螺旋上升
- **不对称**：顺行侧喷流更强

| a 值 | 偏转角 | 螺旋强度 |
|------|--------|---------|
| 0.0 | 0° | 无 |
| 0.3 | 3° | 微弱 |
| 0.5 | 8° | 可见 |
| 0.7 | 15° | 明显 |
| 0.9 | 25° | 强烈 |
| 0.99 | 35° | 极端 |

## 6. 引力透镜

### 施瓦茨柴尔德

- 完美的径向对称偏折
- 背景内容被均匀"挤压"向黑洞
- 爱因斯坦环是完美的亮度增强环

### Kerr

- **方向性偏折**：偏折角度依赖于光子轨道与自转轴的夹角
- **不对称放大**：顺行侧放大率更高
- **扭曲的环**：爱因斯坦环不再是完美圆形

## 7. 帧拖曳可视化

### 直观类比

想象一个旋转的蜂蜜罐：
- 施瓦茨柴尔德 = 静止的蜂蜜罐，物体直接落入
- Kerr = 旋转的蜂蜜罐，物体被蜂蜜拖着旋转

### 视觉表现

- 靠近黑洞的星光被"拖拽"旋转
- 背景星场在黑洞周围形成螺旋状图案
- 吸积盘物质在能层内被强制旋转

## 8. 总结

| 特征 | 施瓦茨柴尔德 | Kerr |
|------|-------------|------|
| 参数 | 1 个 (M) | 2 个 (M, a) |
| 对称性 | 球对称 | 轴对称 |
| 视界 | 固定 r=2M | 随 a 变化 |
| 能层 | 无 | 有 |
| 吸积盘 | 对称 | 不对称 |
| 喷流 | 直线 | 螺旋 |
| 爱因斯坦环 | 圆形 | 扭曲 |
| 真实感 | 低 | 高 |
| 计算复杂度 | 低 | 高 (2-3x) |
