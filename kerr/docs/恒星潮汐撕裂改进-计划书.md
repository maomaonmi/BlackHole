## 0. 为什么必须推翻 v1.0/v1.1

用户实机反馈（原话）：

> 「恒星靠近黑洞时候瞬间被拉成极长的椭圆形，我都没看到过程啊……重点现在的恒星本体就是一个拉伸的椭圆体，没有那种真实宇宙中的能量的感觉。」

**结论：v1.0 的模型在三个维度上都与目标不符，不是参数问题。**

| 维度 | v1.x 的实际行为 | 参考图要求 | 性质 |
|------|----------------|-----------|------|
| 时间尺度 | 拖到位后 **0.25 s** 完成 | 需要 **数秒级**可见过程 | 模型错 |
| 形变对象 | 把**本体**拉成 **8.2R** 长 | 拉长的是**剥离物质流**，本体只轻微变形 | 模型错 |
| 材质 | 完全不透明实心光球 | 弥散气体（低不透明度、蓬松边缘、丝状湍流） | 模型错 |

因此 v2.0 保留「双 shader + 共享单一物理状态」的架构决策（该决策经 v1.x 验证正确），但**替换全部驱动物理量与观感映射**。

## 2. 现状代码证据（v1.1 实测数据）

### 2.1 C1 时间尺度失控 —— 「瞬间」的直接原因

现行积分（[main.cpp](file:///d:/BlackHole/kerr/src/main.cpp#L1967-L1983)）：

$$\dot p = k\,T(r)\,(1-p),\qquad T(r)=\left(\frac{r_t}{r}\right)^{3},\quad k=1.2,\ r_t=0.30$$

$T$ **无上界**，而 $r_t=0.30\ \text{UV}$ 相对真实视界（[main.cpp L493-L495](file:///d:/BlackHole/kerr/src/main.cpp#L493-L495) 算出 $r_h\in[0.019,\ 0.133]$）大 2.3~16 倍：

| $r$ (UV) | $\beta=r_t/r$ | $T=\beta^3$ | 时间常数 $\tau=1/(kT)$ |
|---|---|---|---|
| 0.30 | 1.0 | 1 | 0.83 s |
| 0.20 | 1.5 | 3.38 | 0.25 s |
| 0.15 | 2.0 | 8.0 | **0.104 s** |
| 0.10 | 3.0 | 27 | **0.031 s** |
| 0.05 | 6.0 | 216 | **0.0039 s** |

恒星用一阶跟随鼠标（[main.cpp L2285-L2295](file:///d:/BlackHole/kerr/src/main.cpp#L2285-L2295)，$\tau_{lag}=0.2$ s），径向匀速 $v$ 下：

$$\int T\,dt=\frac{r_t^{3}}{2v}\left(\frac{1}{r_f^{2}}-\frac{1}{r_i^{2}}\right)$$

取 $v=1\,\text{UV/s}$，$r_i=0.30\to r_f=0.10$：$\int T\,dt=1.20$，耗时 **0.2 s**，$p=0.76$；续拖至 $r=0.05$，总耗时 **0.25 s**，$p=0.998$。

> **实测结论：全流程 ≈ 0.25 s ≈ 15 帧。用户「没看到过程」在数据上完全成立。**

## 3. 物理模型

### 3.1 有界潮汐强度（治 C1）

牛顿潮汐加速度差标度 $\Delta a\simeq 2GM_\bullet R_*/r^{3}$，故 $T\propto r^{-3}$ 是对的；**错误在于直接把它当作速率增益**。真实 TDE 的破坏时标由剥离过程决定，应当是**有限时长**。引入：

$$\beta(r)=\frac{r_t}{r},\qquad q(r)=\mathrm{clamp}\!\left(\frac{\beta-1}{\beta_{\max}-1},\,0,\,1\right)\in[0,1]$$

$$\boxed{\ \dot p=\frac{1}{t_{dis}}\Big(0.15+0.85\,q^{\,0.6}\Big)\ }\qquad \beta_{\max}=3.0,\quad t_{dis}=5.0\,\text{s}$$

- $q$：归一化潮汐强度，$q=1$ 对应 $r=r_t/3$；**有界**，从根上消除 $\tau\to0$。
- $t_{dis}$：**在最强档（$q=1$）完全撕裂所需秒数**，语义直观、可直接验收。
- 指数 $0.6$ 使靠近潮汐区边界时也仍有可感速率，避免「边缘处几乎不动」。

由 $\dot p$ 为常数可得完全撕裂时间：

$$t_{full}(q)=\frac{t_{dis}}{0.15+0.85\,q^{0.6}}$$

| 位置（$r_t=0.30,\beta_{\max}=3$） | $\beta$ | $q$ | $t_{full}$ |
|---|---|---|---|
| $r=0.30$（边界） | 1.00 | 0.00 | 33.3 s |
| $r=0.27$ | 1.11 | 0.06 | 16.4 s |
| $r=0.20$ | 1.50 | 0.25 | 9.6 s |
| $r=0.15$ | 2.00 | 0.50 | 7.0 s |
| $r=0.10$ | 3.00 | 1.00 | **5.0 s** |

> 拖到位后约 **5~10 秒**完成，肉眼可完整观察；且**越近越快**，满足 R1。

### 3.2 双量分离（治 C2）

CPU 单点算出两个量并同时喂给本体与流（保持 S4 不变量由**结构**保证，而非靠纪律）：

$$amp_{body}=\text{stretch}\cdot p^{\,0.8}\quad(\text{有界},\ \text{默认}\le 0.6)\qquad\qquad strip=p^{\,1.2}\in[0,1]$$

- $amp_{body}$：仅驱动**本体**形变。上界 $=\text{stretch}$，由构造保证，**不再发散**。
- $strip$：剥离质量份额，驱动**流**的宽度/亮度/色温/包裹角，以及吸积盘/喷流联动。
- $\Rightarrow$ 戏剧性全部转移到流上（R2）。

### 3.3 泪滴形变（位置相关映射）

本体形变从「均匀仿射」升级为「位置相关非均匀映射」——**这才是泪滴与椭圆的本质区别**：

$$\xi=\frac{d_\parallel}{R},\qquad w(\xi)=\mathrm{clamp}(0.5+0.5\,\xi,\,0,\,1)^{1.5}$$
$$A(\xi)=1+amp_{body}\cdot w(\xi),\qquad B=1+(A-1)\cdot 0.55$$
$$d_\parallel \leftarrow d_\parallel/A,\qquad d_\perp \leftarrow d_\perp \cdot B$$

- 逆向映射原理：shader 用 `nr = |d|/R` 判定球体，**收缩采样坐标 = 视觉上拉长形体**。
- $\xi=-1$（背洞侧）$w=0\Rightarrow A=1$ 保持圆；$\xi=+1$（朝洞侧）$A$ 最大 → **前尖后钝的泪滴**。
- $B$ 同步增大 → 鼻部变细。
- 鼻尖解析解：物理 $d_\parallel^{tip}=R\,(1+amp_{body})$（因 $\xi>1$ 时 $w$ 被 clamp 为 1，$A$ 恒定）。

### 3.4 本体消散（R2 / 用户 Q2 决策：本体消失，还原真实）

$$\alpha_{body}=1-0.98\cdot \mathrm{smoothstep}(0.35,\ 1.0,\ p)$$

$p<0.35$ 本体完整；$p\to1$ 本体不可见，**只剩流**。

### 3.5 残留物质 → 吸积盘 / 喷流（R4）

定义全局联动量（取所有活跃恒星的最大剥离强度）：

$$L_{tidal}=\max_{i}\Big(\ \mathbf{1}[stage_i=\text{NORMAL}]\cdot strip_i\ \Big)\in[0,1]$$

$$\text{粒子盘}\ \alpha \times (1+1.5\,L_{tidal}),\qquad \text{主吸积盘}\ gain \times (1+0.8\,L_{tidal}),\qquad \text{jet}\ brt \times (1+2.0\,L_{tidal})$$

## 6. 详细设计

### 6.1 S1：有界潮汐积分（`main.cpp`）

替换 [main.cpp L1967-L1984](file:///d:/BlackHole/kerr/src/main.cpp#L1967-L1984) 的积分块：

```cpp
// ===== 潮汐撕裂积分（S1：有界时间模型）=====
// Why: 旧模型 dot p = k·(r_t/r)^3·(1-p) 中 T 无上界，拖到位后 τ≈0.03s → 0.25s 内完成，
//      用户看不到过程。改为「归一化潮汐强度 + 特征破坏时间」，保证过程持续 5~10s。
{
    // 关键：与 shader 同空间（shader 内统一 d.x *= aspect），否则潮汐区在屏幕上是椭圆
    float tdx = (bhCx - s.x) * aspect;
    float tdy = (bhCy - s.y);
    float tr  = sqrtf(tdx * tdx + tdy * tdy) + 1e-4f;

    if (config.tidalEnabled && s.stage == STAGE_NORMAL) {
        float beta  = config.tidalRadius / tr;
        float q     = (beta - 1.0f) / fmaxf(config.tidalBetaMax - 1.0f, 1e-3f);
        q = fmaxf(0.0f, fminf(1.0f, q));                       // 归一化潮汐强度 ∈[0,1]
        if (q > 0.0f) {
            // q^0.6：让潮汐区边界附近也保有可感速率，避免「边缘几乎不动」
            float rate = (0.15f + 0.85f * powf(q, 0.6f)) / fmaxf(config.tidalDisruptSec, 0.5f);
            s.tidalProgress += rate * dt;
        }
        // 决策：不可逆——被撕开即保持（重新生成恒星只需再点一次左键）
        s.tidalProgress = fmaxf(0.0f, fminf(1.0f, s.tidalProgress));

        // 双量分离：本体（有界）与剥离质量（0→1），均为 CPU 单点计算
        s.tidalAmp    = config.tidalStretch * powf(s.tidalProgress, 0.8f);
        s.tidalStrip  = powf(s.tidalProgress, 1.2f);
    } else {
        s.tidalProgress = 0.0f;
        s.tidalAmp      = 0.0f;
        s.tidalStrip    = 0.0f;
    }
    s_tidalLink = fmaxf(s_tidalLink, s.stage == STAGE_NORMAL ? s.tidalStrip : 0.0f);
}
```

`StarObj` 新增字段（[main.cpp L248-L253](file:///d:/BlackHole/kerr/src/main.cpp#L248-L253) 处追加）：

| 字段 | 类型 | 含义 |
|------|------|------|
| `tidalProgress` | float | $p\in[0,1]$（**上限由 0.96 改为 1.0**；$amp$ 已由 $p^{0.8}$ 有界，无发散风险） |
| `tidalAmp` | float | $amp_{body}$，**语义变更**：本体形变幅度，上界 = `tidalStretch` |

### 6.2 S3：本体泪滴形变 + 气态化 + 消散（`star_frag.glsl`）

替换 [star_frag.glsl L672-L706](file:///d:/BlackHole/kerr/shaders/star_frag.glsl#L672-L706) 的潮汐块：

```glsl
// ===== 潮汐泪滴形变（位置相关非均匀映射）=====
// 逆向映射：canonical = Φ(physical)，形体可见域为 |canonical| <= R
// 与 energy_stream_frag.glsl 的 noseLen/noseWidth 同源（由 CPU 单点 uTidalAmp 保证）
if (uStarStage == 0 && uTidalAmp > 0.001) {
    vec2 bd = uBHPos - uStarPos;  bd.x *= aspect;
    float bdLen = length(bd);
    if (bdLen > 0.001) {
        vec2 bn = bd / bdLen;
        vec2 bq = vec2(-bn.y, bn.x);

        float dPar  = dot(d, bn);
        float dPerp = dot(d, bq);
        float xi    = dPar / R;                       // [-1,1]，+ = 朝洞侧

        // 位置权重：朝洞侧 → 1，背洞侧 → 0。这是「泪滴」与「椭圆」的本质区别
        float w = pow(clamp(0.5 + 0.5 * xi, 0.0, 1.0), 1.5);

        float A = 1.0 + uTidalAmp * w;                 // 径向拉伸（>1 → 采样收缩 → 视觉变长）
        float B = 1.0 + (A - 1.0) * 0.55;              // 横向压缩（≈保面积 → 越拉越细）

        dPar  /= max(A, 0.08);
        dPerp *= B;

        d = dPar * bn + dPerp * bq;
    }
}
```

### 6.6 交界不变量 S4（正确性核心）

| 名称 | 公式 | 出现位置 |
|------|------|----------|
| `noseLen` | $R\,(1+amp_{body})$ | 本体鼻尖解析解；流起点 `p0` 偏移 |
| `noseWidth` | $R\,/(1+amp_{body}\cdot 0.55)$ | 本体鼻部**半宽**；流 `wBase(s=0)` |

### 10.3 单元测试思路（复杂数学：时间模型 + 形变映射 Φ）

```cpp
// 被测 1：时间模型  t_full(q) = t_dis / (0.15 + 0.85·q^0.6)
// 测试 1：dt=1/240 步进模拟，断言 p 到达 1 的时间与解析 t_full 偏差 < 1%   → 覆盖 V3
// 测试 2：单调性 — q 增大时 t_full 严格减小                              → 覆盖 R1「越近越快」
// 测试 3：有界性 — q=0 与 q=1 时 t_full 均有限且 > 0                     → 覆盖 C1
//
// 被测 2：形变映射  canonical(ξ) = ξ / A(ξ)，A(ξ) = 1 + amp·w(ξ)
// 测试 4：单调性 — ξ∈[-1.5,1.5] 步长 1e-3，canonical 严格单调递增         → 覆盖 RK1
// 测试 5：恒等退化 — amp=0 时 canonical(ξ) == ξ（逐点 1e-6）              → 覆盖 G9
// 测试 6：鼻尖解析解 — 二分求 canonical(ξ*) = R，断言 ξ* ≈ 1+amp，相对误差 <1e-3
// 测试 7：横向宽度 — ξ=+1 处半宽收敛、ξ=-1 处半宽 == R                     → 覆盖 G2 形状
```

### 10.4 接缝数值自检

调参模式下 CPU 打印 `noseLen` / `noseWidth`，与流 shader 内同式结果比对，断言 `fabs(diff) < 1e-6`，在「改了一边忘了另一边」时立刻报警。
